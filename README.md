# ORQENVA Small Business Website Starter

A planned, reusable website template for local service businesses.

**Status: Planning. The website has not been implemented yet.**

Created by **Naashon Tshepang Mogakwe**, developer and founder of ORQENVA.

## Goal

Build a clear, responsive website that a small business can personalise with its services, prices, photos and contact details.

## Version 1 scope

- Responsive homepage and mobile navigation
- Services and pricing sections
- Small image gallery
- Email and WhatsApp contact links
- Accessible FAQ with expandable answers

Use clearly labelled demonstration content. Version 1 does not include accounts, payments or a booking backend.

## Technology

HTML, CSS and JavaScript, with no framework required.

## Definition of done

- All five website features work on mobile and desktop.
- Navigation and FAQ controls work with a keyboard.
- Content is readable without horizontal page overflow.
- Demonstration content is clearly identified.
- Contact links use configured details; no invented phone number.
